# Revision Bee

Revision Bee is a Next.js app. This repository uses npm as the only package manager.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Use `npm run build` for production builds. The npm scripts force the canonical `Revision-Bee-HTML` path before running Next.js so Windows path casing cannot mount duplicate router modules.
